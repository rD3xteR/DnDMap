# Глоссарий

Обновлено: 2026-11-12.

| Термин | Значение в проекте |
| --- | --- |
| **Карта (map)** | Изображение-подложка боя (`.png/.jpg/.jpeg`), отображается как фон холста в `MapWindow`. |
| **Токен (Token)** | Круглая иконка существа/персонажа поверх карты. В ядре — `MapToken` (`DnDMap.Core.Model`), в WPF — `TokenViewModel` (`MapWindow/ViewModel/TokenViewModel.cs`). |
| **«Управление»** | Стартовое окно `SettingsWindow`: выбор карты, параметры круга, галерея изображений. |
| **`SettingsViewModel`** | VM окна «Управление»; владеет `MapViewModel`, команды обзора/открытия/добавления, сохранение путей. |
| **`MapViewModel`** | VM окна карты — мост WPF ↔ ядро: команды в `MapSession`, снимок → экранные координаты, hit-test и ввод. Partial: `MainViewModel.cs` (окно/карта), `Properties.cs` (свойства), `Tokens.cs` (токены), `ZoomPan.cs` (кадр). |
| **`MapToken`** | Токен в ядре: `Id` (string), `File`, `EntitySize`, `X/Y` (центр в px карты), `Size` (диаметр в px карты). |
| **`TokenViewModel`** | WPF-представление токена: `Left/Top/Diameter` в px окна + `ImagePath` (абсолютный путь, известен только WPF). |
| **`EntitySize`** | Категория размера существа из ядра: `Normal=1`, `Big=2`, `Huge=3`. Значение = множитель к базовому диаметру. |
| **Диаметр (базовый)** | `SessionOptions.DefaultDiameterReferencePx` = 100 px эталонного экрана, слайдер 20–200. В сессии хранится в px карты: `mapPx = refPx / fitRef`. Итог = базовый × `EntitySize`. |
| **`ImageItem`** | Элемент списка картинок: `Name` (короткое имя файла) + `Path` (полный путь). |
| **`Paths`** | Генерируемый класс пользовательских настроек (`Paths.settings` → `Paths.Designer.cs`): `MapsPath`, `TokensPath`. Сохраняется в `user.config` при закрытии «Управления». |
| **Zoom / ViewState** | Масштаб 1×–3× относительно fit + центр кадра в px карты; в WPF применяется расчётом экранных координат, без `RenderTransform`. |
| **Viewport** | Видимая область (`MainCanvas.ActualWidth/Height` в WPF); хост сообщает её сессии через `SetViewport`. |
| **Inno Setup / ISCC** | Технология установщика (с 2026-10-26): `DnDMap.iss` компилируется `ISCC.exe` в `Setup\DnDMap-Setup.exe`. Установка для текущего пользователя, без UAC. |
| **Squirrel / releasify** | Устаревшая технология установщика (до 2026-10-26): пакет `squirrel.windows` 2.0.1 + `Squirrel.exe --releasify`. Удалена из проекта, оставлена только в истории (см. decisions/troubleshooting). |
| **Self-contained** | Режим публикации: приложение включает .NET-рантайм — на машине игрока ничего устанавливать не нужно (артефакт больше). |
| **`BaseOutputPath`** | Свойство MSBuild: каталог вывода сборки, задан `..\..\..\DndMap` (вне репозитория). |
| **Partial VM** | Приём проекта: один класс ViewModel разнесён по нескольким файлам-`partial`. |
| **«Lazy development»** | Статус из README: основная функциональность работает, часть фич «отложена». |

## Ядро, кадр и сеть (с 2026-11-10)

| Термин | Значение в проекте |
| --- | --- |
| **`DnDMap.Core`** | Общее ядро без UI (`src/DnDMap.Core`, `net10.0`): геометрия кадра, модель сессии, хранилище, протокол. Используется WPF (M1), сервером (M2) и Android-хостом (M3). |
| **Пиксели карты (map px)** | Единая система координат ядра: `MapPoint`/`RectD` в пикселях исходного изображения карты. Не зависит от экрана, окна и зума. |
| **Экранные пиксели (screen px)** | Координаты конкретного viewport (окно WPF, canvas в браузере). Пересчёт — только через `ViewGeometry`. |
| **`MapPoint`** | `readonly record struct (double X, double Y)` в пикселях карты. |
| **`RectD`** | Прямоугольник в пикселях карты (`X/Y` — левый верхний угол). |
| **`ViewState`** | Кадр: `Center` (центр видимой области в пикселях карты) + `Zoom` относительно fit. |
| **`ViewContext`** | Размеры карты + живого viewport; от них считается `FitScale`. |
| **`FitScale`** | Масштаб «карта целиком вписана во viewport» = `min(vw/mw, vh/mh)`. Экранных px на пиксель карты. |
| **Zoom** | Множитель к `FitScale`, диапазон **1..3**. `1` — карта вписана, `3` — максимальное приближение. |
| **`visibleRect`** | Видимая область в пикселях карты (`ViewGeometry.VisibleRect` = `viewport / (fit × zoom)`). Публикуется клиентам, чтобы стол и браузер рисовали одинаковый кадр. Если зум «не работает» — проверять это поле. |
| **`ViewGeometry`** | Единственный источник правды по математике кадра: fit, clamp, зум к точке, панорама, экран ↔ карта. |
| **Clamp (кадра)** | Ограничение центра: карта не уезжает за край; если меньше viewport — центрируется по этой оси. |
| **`MapSession`** | Состояние игры (карта, токены, кадр) + `Apply(Command)` + `Revision` + событие `Changed`. Один экземпляр на хост. |
| **`Command`** | Полиморфная команда изменения (`setMap`, `addToken`, `moveToken`, …), JSON-дискриминатор `type`. |
| **`SessionSnapshot` / `SessionDto`** | Согласованный снимок состояния под одним lock; DTO — его вид для сети. |
| **Revision** | Монотонно растущий номер состояния; клиент по нему отбрасывает устаревшие ответы. |
| **`SessionChange`** | Событие «что изменилось» (`Map`/`Tokens`/`View`/`Diameter`/`Viewport`) — по нему сервер выбирает SSE-событие. |
| **SSE (Server-Sent Events)** | Односторонний поток событий сервер → браузер (`text/event-stream`). В M2 реализовано: событие `state` с полным `SessionDto`, ping каждые 15 с. |
| **`MapServer`** | HTTP-хост стола (`src/DnDMap.Server/MapServer.cs`): `TcpListener`, REST + SSE + SPA из ресурсов, свой `MapSession`. Запускается кнопкой в «Управлении». |
| **SPA / веб-пульт** | Одностраничный клиент мастера (`wwwroot/{index.html,app.css,app.js}`), встроен в сборку как `EmbeddedResource`. Работает без интернета и CDN. |
| **Self-host** | Схема работы: планшет поднимает HTTP-сервер в локальной сети, ноутбук мастера подключается браузером. Интернет не нужен. |
| **`IFileStore` / `PhysicalFileStore`** | Абстракция хранилища карт/токенов и реализация на папке (`maps/`, `tokens/`), с защитой от path traversal. |
| **`ImageSizeReader`** | Чтение размеров PNG/JPEG из заголовка без `System.Drawing` (на Android его нет). |
| **Эталонный экран** | `SessionOptions.ReferenceViewport = 1920×1080`: в его пикселях задан базовый диаметр токена (100) и слайдер 20–200. |
| **`LegacyParityTests`** | Тесты, доказывающие совпадение новой геометрии со старой `ZoomPan.cs` (`LegacyView`). |
| **Кэш сессии (планшет)** | Временная папка `FilesDir/session-cache/{maps,tokens}` на Android (в WPF — `%LOCALAPPDATA%\DnDMap\session-cache`): только то, что мастер прислал в текущей сессии. Чистится при старте/выходе. Не библиотека. |
| **Экран стола / `display=1`** | Режим SPA для планшета: только карта во весь экран, без шапки и панели, ввод отключён. Открывается Android-хостом в WebView. |
| **`/api/viewport`** | `POST {width,height}` от экрана стола: задаёт `SetViewport` сессии, чтобы fit и `visibleRect` соответствовали реальному экрану планшета. |
| **Android-хост (M3)** | `src/DnDMap.Android` (`net10.0-android`, `ru.dndmap.host`): Activity поднимает `MapServer` и показывает SPA в WebView; кэш в `FilesDir`, экран не гаснет. |
| **Источник файлов** | Ноутбук мастера: браузер выбирает файлы/папку и отправляет их на планшет. Планшет файлы не «открывает». |
| **Манифест файлов** | Список «что уже лежит в кэше»: имя, размер, хэш. Браузер сравнивает со своими файлами в IndexedDB и досылает недостающие. |
| **IndexedDB** | Хранилище браузера, где мастер держит последние выбранные карты/токены, чтобы не выбирать их заново при следующем подключении. |
| **Санитизация имени** | Больше не нужна как отдельная сущность: в M2 `ValidateName` разрешает пробелы/кириллицу и запрещает только небезопасные имена (разделители, `CON`, хвостовые точка/пробел). |
